# 2024/ 3  
### ==3-29 利用產業趨勢找股票？如何克服心魔？==  
1. 找股票不是聽明牌或是看誰漲得多，而是關注產業前景，尋找是否有任何影響產業本質的利多消息，確認後計算該產業的個股現價及目標價（需確認是否已反映此次質變），若尚未反應則勇敢抱住長期持有，等待超過目標價後賣出訊號到來。  
2. 持有過程中不應在意短期的上衝下洗，應設立並堅守自己的投資紀律，避免受到情緒影響做出不理智的買賣行為。若很容易受影響，可透過冥想、心流訓練等方法來強化內心。  
*4-17補充  
看新聞或論壇是很好尋找機會的方法，但要注意的是不要只是順著新聞思考就決定買入或賣出，要習慣思考相反面，好消息就思考是否有啥負面影響是沒提到的，壞消息則思考有沒有什麼情況會變利多，甚至思考到對其他產業的影響都可以，習慣第二層思考才有機會在消息平等的情況下找到獲利機會！

### ==3-31 如何選股？該注意哪些重點？賣出三要件！==  
1. 好的投資者不該聽明牌跟單或亂買他人/新聞推薦股票，前者是你本身沒做研究，他人若研究有問題也無法辨識，即使他人研究沒問題也不知道別人的進出場紀律；後者是大家若都說哪檔股票好時往往股價已反映，此時進場反而危險。  
2. 好的投資者應該自己研究股票，研究股票要從自己熟悉/看得懂的產業開始，隨便研究不懂的產業不僅要付出很大的力氣，也未必能比其他熟該產業的投資者看的深入，認知相對不深的狀況下自然不容易賺到錢。  
3. 研究產業不僅要關注趨勢和消息，更要聽股東會以及看電子報，聽股東會可以了解公司打算做什麼、領導層的想法，看年報/財報則可以了解公司經營狀況。（看電子報要看註釋來了解細項），若能做到這幾點則可透過公司財務、經營狀況了解公司體質，透過公司展望、趨勢了解未來發展，並觀察是否出現攻擊量買在起漲點。  
4. 賣出三要件為上引線、爆大量、跌破五日線，上引線代表股價可能到大戶出場點故大量拋售股票將股價打下來，成長中的股票爆大量則代表有一批人或許賺夠離場了，跌破五日線則代表短期內漲勢走弱。若股價已超過目標價又出現賣出三要件，則代表股價可能也到一大批看好這支股票長期佈局投資者的目標價，此時應嚴守紀律賣出，若賣出後股價續漲，則應檢視是否有自己不知道或看錯的地方，重新估算目標價並判斷是否適合繼續持有。  
  
* 4/26音檔補充  
投資一定要了解公司，所以務必要聽法說會，甚至可以打去公司詢問發言人，不要只是google搜尋，只用搜尋往往只能看到新聞中片面說法。  
  
* 5/14音檔補充  
賣出三要件為什麼重要，爆大量代表主力可能跑了，跌破五日線代表技術分析的人可能來空這檔股票，上引線代表突破不了該價位後被賣下來。  
  
* 7/10音檔補充  
出現賣出三要件股價大跌後還可不可以買？  
如果跌很深且公司狀況也都還很好那可以買，但要注意有沒有量，如果沒有就要小心，因為爆大量跌下來那波很多人套在那想脫手，沒有量很可能會被他們賣下來。  
  
* 賣出三要件不代表必然下跌，只代表上漲遇到另一個方向的阻力（通常呈現方式為上引線或大黑k），若目標價已達到且公司未來也沒有很強的成長那就很難再有另一次上升，但若目標價未達到或還能成長那等盤整或換手完後很容易又上漲。
