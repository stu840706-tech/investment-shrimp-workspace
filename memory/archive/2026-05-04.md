### 根本原因：日期格式不一致
- `news_brief_sent.json` 用 `YYYY-MM-DD` 格式（例：`2026-05-03-AM`）
- 當 pipeline 傳 `date_str='20260503'`（YYYYMMDD）時，`today_str=date_str` 直接使用 YYYYMMDD
- `check_already_sent('20260503', 'AM')` 查不到 `2026-05-03-AM`，導致重複發送被錯誤放過
- 而已發送狀態卻又因格式問題無法正確寫入

### 修復內容
**news_publisher.py 行 206：**
```python
# Normalize date_str (YYYYMMDD) to YYYY-MM-DD for sent_state key
if len(date_str) == 8:
    today_str = f"{date_str[:4]}-{date_str[4:6]}-{date_str[6:8]}"
else:
    today_str = date_str
```
